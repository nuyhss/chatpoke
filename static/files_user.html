파일 업로드

일반 사용자가 파일 업로드를 신청하고, 관리자가 승인하면 챗봇 문서에 반영됩니다.

파일 업로드 신청

문서를 선택하고 공개 범위를 지정하면 관리자 검토 대기 목록으로 들어갑니다.

PDF, PNG, JPG, JPEG, WEBP 파일을 업로드할 수 있습니다.
private 문서는 최소 한 개 이상의 부서를 선택해야 합니다.
신청 후에는 관리자 승인 전까지 챗봇 검색 대상에 포함되지 않습니다.

내 신청 목록

방금 올린 파일이 승인 대기인지, 승인 완료인지 여기서 바로 확인할 수 있습니다.

아직 올린 신청이 없습니다.
